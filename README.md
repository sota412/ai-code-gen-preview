# 🤖 AI Code Generator

リアルタイムプレビュー付きのAIコード生成ツール。自然言語のプロンプトからHTML/CSS/JavaScript、React、Vueのコードを自動生成します。

## ✨ 機能

- **AI自動生成**: OpenAI GPT-4を使用して自然言語からコードを生成
- **リアルタイムプレビュー**: 生成されたコードをリアルタイムでプレビュー表示
- **複数のコードタイプ対応**:
  - HTML + CSS + JavaScript
  - React Component
  - Vue Component
- **コードコピー**: ワンクリックでコードをクリップボードにコピー
- **ダウンロード**: 生成されたコードをファイルとしてダウンロード
- **状態保存**: プロンプトとAPI Keyをブラウザに安全に保存

## 🚀 使い方

### 1. デプロイ

```bash
# リポジトリをクローン
git clone https://github.com/sota412/ai-code-gen-preview.git
cd ai-code-gen-preview

# ローカルサーバーで実行
python -m http.server 8000
# または
npx http-server
```

### 2. API Key の設定

1. [OpenAI Platform](https://platform.openai.com/api-keys) で API Key を取得
2. アプリケーションの「OpenAI API Key」フィールドに貼り付け

### 3. コード生成

1. 「何を作りたいですか？」にプロンプトを入力
2. 「コードタイプ」で生成するコードの種類を選択
3. 「✨ コード生成」ボタンをクリック
4. 右側のプレビューでリアルタイムに確認

## 📝 プロンプトの例

### HTML/CSS/JavaScript
```
青と白のグラデーション背景にボタンがあるシンプルなランディングページを作成してください。
ボタンをクリックするとアラートが表示されるようにしてください。
```

### React
```
カウンターアプリを作成してください。
プラスボタンとマイナスボタンがあり、クリックするとカウントが増減します。
カウントが10を超えたら警告メッセージを表示してください。
```

### Vue
```
TODOリストアプリを作成してください。
タスクの追加、削除、完了状態の切り替えができるようにしてください。
```

## 🔐 セキュリティ

- **API Key はローカルストレージに保存**: ブラウザのローカルストレージにのみ保存され、サーバーには送信されません
- **直接API呼び出し**: クライアント側から直接 OpenAI API に通信します
- **HTTPS推奨**: 本番環境では HTTPS を使用してください

## 🛠️ 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript
- **API**: OpenAI GPT-4
- **ストレージ**: ブラウザ LocalStorage

## 📋 必要な環境

- モダンなブラウザ (Chrome, Firefox, Safari, Edge)
- OpenAI API Key
- インターネット接続
